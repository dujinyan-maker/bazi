# 用户注册发送验证码接口 - Apifox 测试文档

## 接口信息

### 接口名称
用户注册时发送验证码

### 接口地址
```
POST http://localhost:8081/auth/account/register/sendCode
```

### 请求方法
`POST`

### Content-Type
`application/x-www-form-urlencoded` 或使用查询参数

## Apifox 配置步骤

### 步骤 1：创建新请求

1. 打开 Apifox
2. 点击左侧菜单的 **接口** 或 **API**
3. 点击 **+** 号创建新接口
4. 命名为：`用户注册-发送验证码`

### 步骤 2：配置请求基本信息

1. **请求方法**：选择 `POST`
2. **请求URL**：`http://localhost:8081/auth/account/register/sendCode`
3. **Content-Type**：选择 `application/x-www-form-urlencoded`（如果使用表单参数）或留空（如果使用查询参数）

### 步骤 3：配置请求参数

#### 方式一：使用查询参数（推荐）

1. 点击 **Params** 标签页
2. 添加参数：
   - **参数名**：`phone`
   - **参数值**：`13800138000`
   - **必填**：勾选 ✅

#### 方式二：使用表单参数

1. 点击 **Body** 标签页
2. 选择 `form-data` 或 `x-www-form-urlencoded`
3. 添加参数：
   - **参数名**：`phone`
   - **参数值**：`13800138000`
   - **必填**：勾选 ✅

### 步骤 4：发送请求

1. 点击右上角的 **发送** 按钮
2. 查看响应结果

## 注意事项

1. **测试模式**：
   - 当前系统处于测试模式（`sms.test-mode: true`）
   - 验证码不会真正发送短信，而是打印在控制台日志中
   - 控制台会显示：`【验证码】手机号: xxx`、`【验证码】验证码: xxxxxx`

2. **验证码有效期**：
   - 默认有效期：5 分钟
   - 可在 `application.yml` 中配置：`sms.code.expire-minutes`

3. **发送频率限制**：
   - 默认发送间隔：60 秒
   - 可在 `application.yml` 中配置：`sms.code.send-interval-seconds`
   - 如果发送过于频繁，会返回失败

4. **验证码格式**：
   - 6 位数字
   - 例如：`123456`、`654321`

5. **服务器地址**：
   - 开发环境：`http://localhost:8081`
   - 生产环境：需要修改为实际服务器地址

## 常见问题

### Q1: 验证码在哪里查看？
**A**: 在测试模式下，验证码会打印在服务器控制台日志中，格式如下：
```
========================================
【验证码】手机号: 13800138000
【验证码】验证码: 123456
【验证码】有效期: 5分钟
========================================
```

### Q2: 为什么提示"发送验证码过于频繁"？
**A**: 系统有发送频率限制，默认 60 秒内只能发送一次。请等待 60 秒后重试。

### Q3: 验证码有效期是多久？
**A**: 默认 5 分钟，可以在配置文件中修改。

### Q4: 生产环境如何配置真实短信发送？
**A**: 需要：
1. 将 `sms.test-mode` 设置为 `false`
2. 集成真实的短信服务（如阿里云短信、腾讯云短信等）
3. 在 `PhoneLoginServiceImpl` 中实现真实的短信发送逻辑
