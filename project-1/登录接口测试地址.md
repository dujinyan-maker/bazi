# 微信小程序登录接口 - 测试地址

## 基础信息

- **服务器地址**: `http://localhost:8081`
- **Content-Type**: `application/json`

---

## 测试接口地址

### 1. 完整版登录接口（手机号一键登录）- 推荐使用

**接口地址：**
```
POST http://localhost:8081/auth/login
```

**请求头：**
```
Content-Type: application/json
```

**请求体（JSON）：**
```json
{
  "code": "test_code_123456",
  "encryptedData": "test_encrypted_data",
  "iv": "test_iv",
  "nickname": "测试用户",
  "avatarUrl": "https://example.com/avatar.jpg"
}
```

**完整请求示例（可直接复制到Apifox）：**
```http
POST http://localhost:8081/auth/login
Content-Type: application/json

{
  "code": "test_code_123456",
  "encryptedData": "test_encrypted_data",
  "iv": "test_iv",
  "nickname": "测试用户"
}
```

---

### 2. 简化版登录接口（仅用于测试，不包含手机号）

**接口地址：**
```
POST http://localhost:8081/auth/login/simple?code=test_code_123456
```

**或者使用POST Body：**
```http
POST http://localhost:8081/auth/login/simple
Content-Type: application/x-www-form-urlencoded

code=test_code_123456
```

---

## Apifox快速测试

### 方式1：直接在Apifox中创建请求

1. **创建新请求**
   - 方法：`POST`
   - URL：`http://localhost:8081/auth/login`

2. **设置请求头**
   ```
   Content-Type: application/json
   ```

3. **设置请求体（Body - JSON）**
   ```json
   {
     "code": "test_code_123456",
     "encryptedData": "test_encrypted_data",
     "iv": "test_iv",
     "nickname": "测试用户"
   }
   ```

4. **发送请求**

### 方式2：使用环境变量

在Apifox中创建环境，设置：
- `baseUrl` = `http://localhost:8081`

然后使用：
- URL：`{{baseUrl}}/auth/login`

## 注意事项

1. **测试时**：
   - 可以使用假的 `code`、`encryptedData`、`iv` 进行测试
   - 但实际生产环境必须使用真实的微信小程序获取的值

2. **真实环境**：
   - `code` 需要通过小程序 `wx.login()` 获取
   - `encryptedData` 和 `iv` 需要通过 `getPhoneNumber` 获取

3. **Token使用**：
   - 登录成功后，保存返回的 `token`
   - 后续需要认证的接口，在Header中携带：`Authorization: Bearer {token}`
