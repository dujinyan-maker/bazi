# 祝福语/弹幕功能使用说明

## 功能概述

祝福语/弹幕功能允许用户：
1. 发送祝福语（类似弹幕）
2. 查看所有用户的祝福语列表
3. 查看自己的祝福语列表
4. 删除自己的祝福语

## 数据库设置

### 1. 执行 SQL 脚本

执行 `src/main/resources/sql/blessing_message_table.sql` 创建祝福语表。

```sql
CREATE TABLE IF NOT EXISTS `blessing_message` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `user_id` BIGINT NOT NULL COMMENT '用户ID（关联users表）',
  `content` TEXT NOT NULL COMMENT '祝福语内容',
  `status` TINYINT(1) DEFAULT 1 COMMENT '状态：1-正常显示，0-已删除/隐藏',
  `created_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '发送时间',
  `updated_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_created_time` (`created_time`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='祝福语/弹幕表';
```

## 配置文件

在 `application.yml` 中已添加配置：

```yaml
blessing:
  message:
    max-length: 200  # 祝福语最大长度（字符）
    default-limit: 50  # 默认查询数量
```

## API 接口

### 1. 发送祝福语

**接口地址**：`POST /blessing/send`

**请求头**：
```
Authorization: Bearer {token}
Content-Type: application/json
```

**请求体**：
```json
{
  "content": "祝大家新年快乐，万事如意！"
}
```

**响应示例**：
```json
{
  "code": 200,
  "message": "发送成功",
  "data": {
    "id": 1,
    "userId": 1,
    "nickname": "用户8000",
    "content": "祝大家新年快乐，万事如意！",
    "createdTime": "2026-01-06T10:00:00"
  }
}
```

### 2. 获取所有祝福语列表（弹幕列表）

**接口地址**：`GET /blessing/list?limit=50`

**参数说明**：
- `limit`（可选）：限制返回数量，默认 50

**响应示例**：
```json
{
  "code": 200,
  "message": "查询成功",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "nickname": "用户8000",
      "content": "祝大家新年快乐！",
      "createdTime": "2026-01-06T10:00:00"
    },
    {
      "id": 2,
      "userId": 2,
      "nickname": "用户9000",
      "content": "身体健康，工作顺利！",
      "createdTime": "2026-01-06T09:55:00"
    }
  ]
}
```

### 3. 获取当前用户的祝福语列表

**接口地址**：`GET /blessing/my?limit=20`

**请求头**：
```
Authorization: Bearer {token}
```

**参数说明**：
- `limit`（可选）：限制返回数量，默认 50

**响应示例**：
```json
{
  "code": 200,
  "message": "查询成功",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "nickname": "用户8000",
      "content": "祝大家新年快乐！",
      "createdTime": "2026-01-06T10:00:00"
    }
  ]
}
```

### 4. 删除祝福语

**接口地址**：`DELETE /blessing/{messageId}`

**请求头**：
```
Authorization: Bearer {token}
```

**路径参数**：
- `messageId`：祝福语ID

**响应示例**：
```json
{
  "code": 200,
  "message": "删除成功"
}
```

## 使用示例

```bash

  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Content-Type: application/json" \
  -d '{

```

### 示例 2：获取所有祝福语

```bash
curl -X GET "http://localhost:8081/blessing/list?limit=20"
```


## 功能特点

1. **用户认证**：发送和删除需要登录（通过 JWT Token）
2. **权限控制**：用户只能删除自己的祝福语
3. **软删除**：删除时只更新状态，不物理删除数据
4. **内容限制**：祝福语内容最大长度 200 个字符
5. **时间排序**：列表按发送时间倒序排列（最新的在前）

## 数据库字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键ID，自增 |
| user_id | BIGINT | 用户ID，关联 users 表 |
| content | TEXT | 祝福语内容 |
| status | TINYINT | 状态：1-正常显示，0-已删除/隐藏 |
| created_time | DATETIME | 发送时间 |
| updated_time | DATETIME | 更新时间 |

## 索引说明

- `idx_user_id`：用户ID索引，用于快速查询用户的祝福语
- `idx_created_time`：创建时间索引，用于排序
- `idx_status`：状态索引，用于筛选正常显示的祝福语

## 注意事项

1. **内容长度限制**：
   - 默认最大长度：200 个字符
   - 可在 `application.yml` 中配置：`blessing.message.max-length`

2. **查询数量限制**：
   - 默认查询数量：50 条
   - 可在 `application.yml` 中配置：`blessing.message.default-limit`
   - 接口支持通过 `limit` 参数自定义

3. **权限验证**：
   - 发送祝福语需要登录
   - 删除祝福语需要登录，且只能删除自己的
   - 查看所有祝福语不需要登录

4. **软删除**：
   - 删除操作是软删除（更新状态为 0）
   - 数据不会物理删除，可以用于数据恢复或统计

5. **性能优化建议**：
   - 如果祝福语数量很大，建议添加分页功能
   - 可以考虑使用 Redis 缓存热门祝福语
   - 可以考虑添加内容审核功能
